# 💊 MediTrack – Medicine Management App

🔗 **Live App:** https://meditrack-react-2026.netlify.app/
🔗 **GitHub Repository:** https://github.com/akashkashyap0770/meditrack-react-2026

A modern, fully responsive **Medicine Management Web Application** built using **React + Vite + Tailwind CSS**.  
This project allows users to add, edit, view, delete, and search medicines easily — with all data saved in **LocalStorage** so records stay safe even after page refresh.

## 🛠 Tech Stack

- ⚛️ React 19
- ⚡ Vite
- 🎨 Tailwind CSS
- 🔀 React Router
- 🗂️ Context API (Global State)
- 💾 LocalStorage (Data Persistence)

---

## 📌 Key Features

- ✅ Add New Medicine Records
- ✅ Edit Existing Medicine Details
- ✅ View All Saved Medicines
- ✅ Delete Medicine Entries
- ✅ Instant Search / Filter
- ✅ LocalStorage — Data stays after page refresh
- ✅ Medicine Cards Component
- ✅ Fully Responsive Layout (Mobile, Tablet, Desktop)

## 📁 Project Structure

```
src/
├── components/
│   ├── MedicineCards.jsx    # Medicine card UI
│   ├── Navbar.jsx           # Navigation bar
│   └── SearchBar.jsx        # Search/filter component
├── context/
│   └── MedicineContext.jsx  # Global state (Context API)
├── pages/
│   ├── Home.jsx             # All medicines listing
│   ├── AddMedicine.jsx      # Add new medicine form
│   └── EditMedicine.jsx     # Edit existing medicine
└── App.jsx                  # Routes setup
```

## 🚀 Installation & Setup

Clone the repo:
```bash
git clone https://github.com/akashkashyap0770/meditrack-react-2026.git
```

Install dependencies:
```bash
npm install
```

Start dev server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
